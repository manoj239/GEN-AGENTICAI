The objective of this POC was to demonstrate enterprise workflow automation using Agentic AI. 
I developed an n8n workflow where a form submission acts as the trigger. The submitted request
is sent to a Gemini-powered AI agent.The AI agent uses MCP to discover and interact with
enterprise tools such as Jira, GitHub, and Confluence. Based on the user's request, it can perform 
actions like creating Jira tickets, retrieving GitHub repository information, fetching Confluence
documentation, and generating summaries. MCP provides a standardized way for the agent to access 
these tools without requiring custom integrations for every application. The workflow combines 
AI-driven decision-making with enterprise tool automation, reducing manual effort and improving
operational efficiency.
